# Customer_Shopping_Trend_Analysis
A data analysis project exploring customer shopping behavior and segmentation patterns using Python and SQL. The goal is to uncover actionable insights into how different customer segments shop — what they buy, how often, and how much they spend — to support smarter, data-driven business decisions.
<br>
<br>
--METHODOLOGY
<br>
<br>
Data Extraction & Cleaning (SQL) — Queried raw transactional data, handled duplicates/nulls, and aggregated customer-level metrics (total spend, order frequency, average basket size, recency).
Customer Segmentation (Python) — Grouped customers based on behavioral metrics (e.g. RFM — Recency, Frequency, Monetary analysis) to identify distinct segments such as loyal high-spenders, occasional buyers, and at-risk/churn-prone customers.
Exploratory Data Analysis — Visualized spending patterns, category preferences, and purchase frequency across segments.
Insights & Recommendations — Translated findings into business-relevant takeaways.
